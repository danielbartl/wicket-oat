Oat Dialog, Tabs & More

Tooltip

Oat automatically styles the standard title attribute with a smooth transition.

How to use

Use TooltipBehavior to set the title attribute on any component.

// Java
button.add(new TooltipBehavior("My Tooltip Content"));
<!-- HTML -->
<button wicket:id="button">Hover me</button>

Dialog

Oat styles native <dialog> elements.

Title

This is a native dialog styled by Oat. It can contain any HTML.

How to use

Use a native <dialog> element in your markup and wrap it with a WebMarkupContainer in Java if you need to manage its content.

// Java
WebMarkupContainer dialog = new WebMarkupContainer("dialog");
add(dialog);

// Trigger button
add(new WebMarkupContainer("open").add(new ClientSideClickBehavior("document.getElementById('my-id').showModal()")));
<!-- HTML -->
<dialog id="my-id" wicket:id="dialog">
    <header><h3>Title</h3></header>
    <p>Content...</p>
    <footer><button>Close</button></footer>
</dialog>

Tabs

Oat provides a <ot-tabs> Web Component.

Manage your account information here.

Change your password here.

Notification Settings

Configure your notification preferences.

How to use

Use the <ot-tabs> Web Component in your markup. Organize content with role="tablist", role="tab", and role="tabpanel".

// Java
add(new WebMarkupContainer("tabs"));
<!-- HTML -->
<ot-tabs wicket:id="tabs">
    <div role="tablist">
        <button role="tab">Tab 1</button>
    </div>
    <div role="tabpanel">Content 1</div>
</ot-tabs>

Toast

Trigger a programmatic toast.

How to use

Toasts are triggered programmatically via JavaScript using ot.toast(message, options). To comply with CSP, use ClientSideClickBehavior to attach the listener.

// Java - adding a trigger on a Component
button.add(new ClientSideClickBehavior("ot.toast('Success!', {variant: 'success', title: 'Great news!'})"));
<!-- HTML -->
<button wicket:id="button">Show Toast</button>

Options include variant, title, and duration (in ms).

How to use

To apply Oat's default typography styling, wrap your content in an <article> tag. It styles headings, paragraphs, blockquotes, and lists automatically.

// Java
add(new WebMarkupContainer("typography"));
<!-- HTML -->
<article wicket:id="typography">
    <h1>Title</h1>
    <p>Content...</p>
</article>
