Oat Button Demo

Buttons in Oat are styled from native <button> or <a class="button"> elements. ButtonBehavior automatically handles these.

Default Secondary Danger

Styles

Outline Ghost

Sizes

Icon Style

How to use

Simply add ButtonBehavior to any Wicket component (like Link, Button, or even WebMarkupContainer).

// Java - Using Behavior on a Link
link.add(new ButtonBehavior(ButtonBehavior.Variant.SECONDARY)
    .setStyle(ButtonBehavior.Style.OUTLINE)
    .setSize(ButtonBehavior.Size.SMALL));
<!-- HTML - Markup: can be <a>, <button>, or even <div> -->
<a wicket:id="link">Click me</a>
