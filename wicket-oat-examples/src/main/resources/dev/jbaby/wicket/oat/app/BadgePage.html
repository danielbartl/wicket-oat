Oat Badge Demo

Badges are small status indicators or labels. In the Oat framework, they are created by applying the .badge class to a <span> or similar inline element.

Variants

How to use

You can use the OatBadge component for a simple label, or attach BadgeBehavior to any existing component.

// Java - Using the OatBadge component via the Oat factory (recommended)
add(Oat.badge("myBadge", "Success", BadgeBehavior.Variant.SUCCESS));

// Java - Using the BadgeBehavior via the Oat factory
label.add(Oat.badge(BadgeBehavior.Variant.SUCCESS));
<!-- HTML - Markup for both approaches -->
<span wicket:id="myBadge"></span>
<span wicket:id="myLabel"></span>
