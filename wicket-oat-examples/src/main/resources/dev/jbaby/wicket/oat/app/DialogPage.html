Oat Dialog Demo

A modal dialog built on the native <dialog> element. Cancel, the Escape key and a click on the backdrop close it natively; Confirm validates the fields in its body and calls onConfirm over Ajax.

Confirmation

With a trigger label, the dialog renders its own button, which opens it without a server round trip.

// Java
add(new OatDialog("deleteDialog", Model.of("Delete item"), Model.of("Delete item?")) {
    @Override
    protected void onConfirm(AjaxRequestTarget target) {
        success("Item deleted.");
    }
}.setBody(new Label(OatDialog.BODY_ID, "This action cannot be undone."))
        .setConfirmLabel(Model.of("Delete"))
        .setConfirmVariant(ButtonBehavior.Variant.DANGER));
<!-- HTML -->
<div wicket:id="deleteDialog"></div>

Editing from the server

Open a dialog from any Ajax handler with dialog.open(target), which re-renders it first. Its body sits in the dialog's own form: clear a field and click Save, and the dialog stays open with the error shown inline.
