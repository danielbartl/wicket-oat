Tutorial

Build a Contact Form

A step-by-step walkthrough of assembling a real, validated Wicket page with Oat's form components — from an empty form to a working submit handler.

This picks up right after the Quick Start steps on the homepage — we'll assume you've already called WicketOats.install(this) in your application's init(). Every snippet below uses real component signatures, checked against the library source.

1

The model

Start with a plain model object and a Form bound to it — nothing Oat-specific yet, just standard Wicket.

// A simple model object
public static class ContactMessage implements Serializable {
    public String name;
    public String email;
    public String message;
}
// Inside your page's constructor
ContactMessage data = new ContactMessage();
CompoundPropertyModel<ContactMessage> model = new CompoundPropertyModel<>(data);
Form<ContactMessage> form = new Form<>("contactForm", model);
add(form);
2

Add the name field

Oat.Components.textField(...) gives you a labeled text input with a feedback slot, bound to the model by property name.

form.add(Oat.Components.textField("name", "Your Name", model.bind("name"))
    .setRequired(true));
3

Add the email field

Same shape, a different field type — emailField renders a native <input type="email">.

form.add(Oat.Components.emailField("email", "Email Address", model.bind("email"))
    .setRequired(true));
4

Add the message field

textArea follows the exact same pattern, just backed by a <textarea> instead of an <input>.

form.add(Oat.Components.textArea("message", "Message", model.bind("message"))
    .setRequired(true));
5

Add the submit button and feedback

An AjaxButton styled with Oat.Behaviors.button() submits the form over Ajax. onSubmit and onError are where you hook in Oat.toast(...) for feedback.

form.add(new AjaxButton("submit") {
    @Override
    protected void onSubmit(AjaxRequestTarget target) {
        Oat.toast(target, "Thanks, " + form.getModelObject().name + "! We'll be in touch.",
            OatToastBehavior.Variant.SUCCESS, "Message sent");
    }

    @Override
    protected void onError(AjaxRequestTarget target) {
        Oat.toast(target, "Please fix the errors below.", OatToastBehavior.Variant.DANGER, "Error");
    }
}.add(Oat.Behaviors.button()));
6

Validation and accessibility, for free

Every Oat form field extends BaseOatField, which already wires aria-describedby from the input to its feedback message, and toggles aria-invalid/data-field="error" when validation fails — there's no FeedbackPanel to add and no extra markup to write. Submit the real form with an empty field and the error message appears right where the hint text was, already linked to the input for screen readers.

Put it all together

The finished page

public class ContactPage extends WebPage {

    public static class ContactMessage implements Serializable {
        public String name;
        public String email;
        public String message;
    }

    public ContactPage() {
        ContactMessage data = new ContactMessage();
        CompoundPropertyModel<ContactMessage> model = new CompoundPropertyModel<>(data);
        Form<ContactMessage> form = new Form<>("contactForm", model);
        add(form);

        form.add(Oat.Components.textField("name", "Your Name", model.bind("name")).setRequired(true));
        form.add(Oat.Components.emailField("email", "Email Address", model.bind("email")).setRequired(true));
        form.add(Oat.Components.textArea("message", "Message", model.bind("message")).setRequired(true));

        form.add(new AjaxButton("submit") {
            @Override
            protected void onSubmit(AjaxRequestTarget target) {
                Oat.toast(target, "Thanks, " + form.getModelObject().name + "! We'll be in touch.",
                    OatToastBehavior.Variant.SUCCESS, "Message sent");
            }

            @Override
            protected void onError(AjaxRequestTarget target) {
                Oat.toast(target, "Please fix the errors below.", OatToastBehavior.Variant.DANGER, "Error");
            }
        }.add(Oat.Behaviors.button()));
    }
}
<!-- ContactPage.html -->
<wicket:extend>
    <form wicket:id="contactForm" class="vstack gap-4">
        <div wicket:id="name"></div>
        <div wicket:id="email"></div>
        <div wicket:id="message"></div>
        <footer class="hstack justify-end mt-2">
            <button wicket:id="submit" type="submit">Send Message</button>
        </footer>
    </form>
</wicket:extend>
