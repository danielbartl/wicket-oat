Oat Dialog Demo

A fully native modal dialog using <dialog> and command/commandfor attributes. Opening and cancelling need no JavaScript beyond what Oat already vendors; confirming also fires a server-side Ajax callback.

How to use

// Java
OatDialog dialog = new OatDialog("dialog", Model.of("Open dialog"), Model.of("Delete item")) {
    @Override
    protected void onConfirm(AjaxRequestTarget target) {
        Oat.toast(target, "Item deleted.", OatToastBehavior.Variant.DANGER);
    }
};
dialog.setBody(new Label("body", "This action cannot be undone."));
add(dialog);
<!-- HTML -->
<div wicket:id="dialog"></div>
