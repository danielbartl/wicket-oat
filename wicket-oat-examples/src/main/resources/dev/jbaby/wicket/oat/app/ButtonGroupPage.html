Oat Button Group Demo

Button groups are created using OatButtonGroup component, which renders a container with class="buttons".

Default Button Group

How to use

Use OatButtonGroup component and add buttons inside it. Buttons typically use ButtonBehavior. You can mix different styles and variants within the same group.

// Java - Using the Oat factory (recommended)
OatButtonGroup group = Oat.buttonGroup("group");
group.add(new Link<Void>("btn1").add(Oat.button().setVariant(Variant.SECONDARY)));
group.add(new Link<Void>("btn2").add(Oat.button().setVariant(Variant.DANGER)));
add(group);
<!-- HTML -->
<menu wicket:id="group">
    <button wicket:id="btn1">Secondary</button>
    <button wicket:id="btn2">Danger</button>
</menu>
