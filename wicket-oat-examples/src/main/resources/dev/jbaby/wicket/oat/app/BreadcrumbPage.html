Oat Breadcrumb Demo

Breadcrumbs use a semantic <nav> with an ordered list. OatBreadcrumb automatically marks the last item as the current page and hides its trailing separator.

  1. /

How to use

// Java
add(Oat.Components.breadcrumb("breadcrumb", Model.ofList(crumbs), (item, label) -> {
    Link<Void> link = new Link<>("link") { public void onClick() {} };
    link.add(new Label("label", label));
    item.add(link);
}));
<!-- HTML -->
<nav wicket:id="breadcrumb">
    <ol wicket:id="list">
        <li wicket:id="items">
            <a wicket:id="link" class="unstyled"><span wicket:id="label"></span></a>
            <span wicket:id="separator" aria-hidden="true">/</span>
        </li>
    </ol>
</nav>
