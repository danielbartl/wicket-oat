How to use

Form Fields

Use FieldBehavior on a container (like <label> or <div>) to style the field.

// Java
WebMarkupContainer container = new WebMarkupContainer("field");
container.add(new FieldBehavior());
container.add(new TextField<>("input", model));
<!-- HTML -->
<label wicket:id="field">
    Label Text
    <input wicket:id="input" type="text" />
</label>

Switches

Add SwitchBehavior to a CheckBox.

// Java
checkBox.add(new SwitchBehavior());
<!-- HTML -->
<input wicket:id="switch" type="checkbox" />

Feedback

Use SpinnerBehavior or SkeletonBehavior for loading states.

// Java
container.add(new SpinnerBehavior(SpinnerBehavior.Size.SMALL));
container.add(new SkeletonBehavior(SkeletonBehavior.Shape.LINE));
<!-- HTML -->
<div wicket:id="spinner"></div>
<div wicket:id="skeleton"></div>

Progress & Meter

Use the specialized Progress and Meter components. Meter supports advanced ranges like low, high, and optimum.

// Java - Simple Progress
add(new Progress("progress", 60));

// Java - Advanced Meter
add(new Meter("meter", 
    Model.of(0.8), // value
    Model.of(0),   // min
    Model.of(1),   // max
    Model.of(0.3), // low
    Model.of(0.7), // high
    Model.of(1)    // optimum
));
<!-- HTML -->
<progress wicket:id="progress"></progress>
<meter wicket:id="meter"></meter>
