The OatButton Component

Same result, built via the Oat.Components.button(...) factory instead of a plain Link + ButtonBehavior.

How to use

You can use the OatButton component for a simple button, or attach ButtonBehavior to any existing component via the Oat factory.

// Java - Using the OatButton component via the Oat factory
add(Oat.Components.button("myButton", "Click me", target -> {
    // handle click
}));

// Java - Using Behavior on a Link via the Oat factory
link.add(Oat.Behaviors.button()
    .setVariant(OatVariant.SECONDARY)
    .setStyle(ButtonBehavior.Style.OUTLINE)
    .setSize(ButtonBehavior.Size.SMALL));

// Java - A submit button for a form, via the Oat factory
form.add(Oat.Components.submitButton("save", "Save",
        target -> success("Saved."),          // the form is valid
        target -> target.add(form)));         // show the validation errors
<!-- HTML - OatButton renders its label as the tag's text; <a> or <button> -->
<a wicket:id="myButton"></a>
<a wicket:id="link">Click me</a>
