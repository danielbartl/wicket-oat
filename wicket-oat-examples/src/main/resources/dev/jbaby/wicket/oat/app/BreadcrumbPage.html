Oat Breadcrumb Demo

Breadcrumbs use a semantic <nav> with an ordered list. OatBreadcrumb automatically marks the last item as the current page and hides its trailing separator.

A long trail

With setMaxItems(3), a trail of seven levels shows the first, a "…" button whose menu has the ones in between, and the last two. OatPageHeader does the same with setBreadcrumbMaxItems(...). A second trail on a page needs a name of its own for screen readers, here an aria-label in the markup.

How to use

// Java
add(OatBreadcrumb.of("breadcrumb", Model.ofList(crumbs), (item, label) -> {
    Link<Void> link = new Link<>("link") { public void onClick() {} };
    link.add(new Label("label", label));
    item.add(link);
}).setMaxItems(3)); // optional: leave out levels in the middle of a long trail
<!-- HTML -->
<nav wicket:id="breadcrumb"></nav>
