Oat Dropdown Demo

A dropdown menu using the ot-dropdown web component (JS vendored in oat.min.js) and the native popover API.

How to use

// Java
add(Oat.Components.dropdown("dropdown", "Options", Model.ofList(items), (item, label) ->
        item.add(new Label("label", label))));
<!-- HTML -->
<div wicket:id="dropdown"></div>
