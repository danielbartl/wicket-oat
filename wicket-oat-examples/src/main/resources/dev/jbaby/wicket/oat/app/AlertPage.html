Oat Alert Demo

Alerts provide contextual feedback messages for typical user actions. They use the role="alert" attribute and an optional data-variant attribute for styling.

Variants

How to use

The OatAlert component is a container, while AlertBehavior can be added to any Wicket component.

// Java - Using the OatAlert component via the Oat factory (recommended)
add(Oat.Components.alert("myAlert", AlertBehavior.Variant.SUCCESS));

// Java - Using the AlertBehavior via the Oat factory
label.add(Oat.Behaviors.alert(AlertBehavior.Variant.SUCCESS));
<!-- HTML - Markup for the container approach -->
<div wicket:id="myAlert">
    Any markup here...
</div>
