How to use

Use the OatCard component as a container. Inside, you can use standard <header> and <footer> tags in your markup.

// Java - Using the Oat factory (recommended)
OatCard card = Oat.Components.card("card");
add(card);
card.add(new Label("title", "Card Title"));
<!-- HTML -->
<article wicket:id="card">
    <header>
        <h3 wicket:id="title"></h3>
    </header>
    <p>Content...</p>
</article>
