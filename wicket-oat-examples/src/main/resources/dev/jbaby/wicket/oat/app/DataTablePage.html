Oat Data Table Demo

A styled Wicket DataTable with built-in toolbars and empty state support.

Standard Data Table

This table uses a SortableDataProvider and supports pagination and sorting.

Empty Table with Placeholder

If the data provider is empty, the setEmptyState component is displayed.

How to use

Use the OatDataTable component via the Oat factory. It wraps a standard Wicket DataTable and provides convenient methods for common patterns.

// Java - Basic Table
OatDataTable<User, String> table = Oat.dataTable("id", columns, dataProvider, 10);
add(table);

// Java - With Empty State
table.setEmptyState(Oat.emptyState("placeholder", "No results found", Model.of("Try a different search.")));
