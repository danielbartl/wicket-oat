Oat Theming Demo

Oat UI is built with CSS variables, making it extremely easy to create and switch between themes.

Current Theme Integration

We use a custom OatSession to store the theme preference and a OatThemeBehavior to apply it to the <body> tag.

Theme Switcher

Use the sun, moon, and galaxy icons in the sidebar footer to switch themes instantly!

How to use Themes

1. Define Theme CSS

Themes are defined by overriding Oat UI's CSS variables. You should these in a [data-theme="..."] selector.

/* Java - Ensure your CSS is registered */
response.render(CssHeaderItem.forReference(new PackageResourceReference(getClass(), "my-themes.css")));
/* CSS - Define the variables */
[data-theme="midnight"] {
    color-scheme: dark;
    --background: #020617;
    --foreground: #f8fafc;
    --primary: #38bdf8;
    --card: #0f172a;
}

2. Switch Theme Programmatically

Use the OatSession to update the user's preference. Wicket Oat handles the rest by updating the data-theme attribute on the <html> tag.

// Java - In a Link or AjaxButton
public void onClick() {
    OatSession.get().setTheme(OatTheme.MIDNIGHT);
}
<!-- HTML -->
<a wicket:id="switchBtn">Switch to Midnight</a>

3. Apply Theme to the Document

Ensure OatThemeBehavior is attached to your root html or body container in your base layout.

// Java - Usually in AppLayout.java
TransparentWebMarkupContainer html = new TransparentWebMarkupContainer("html");
html.add(new OatThemeBehavior());
add(html);
<!-- HTML - AppLayout.html -->
<html wicket:id="html">
    <body>...</body>
</html>
