Oat Theming Demo

Oat themes are CSS variable sets keyed on the data-theme attribute. OatAppLayout sets it on <html> from the current user's theme, which is kept in a cookie (cached in the session) so it survives the session — no special session class needed.

How to use Themes

1. Configure

// Java - in WebApplication.init()
WicketOats.install(this)
        .setDefaultTheme(OatTheme.LIGHT)                // or null to follow the browser
        .addTheme(new OatTheme("ocean", "Ocean", "🌊")); // a custom theme from your CSS

2. Define custom theme CSS

/* CSS - override Oat's variables for your theme */
[data-theme="ocean"] {
    color-scheme: dark;
    --background: #0b1d2e;
    --foreground: #d6e9f8;
    --primary: #2fb3c9;
    --card: #10283f;
}

3. Switch themes

// Java - e.g. in a Link's onClick()
OatTheme.setCurrent(OatTheme.MIDNIGHT);
OatTheme current = OatTheme.current();

// Or let users pick from the registered themes
add(new OatThemeSwitcher("themes"));

4. Apply the theme

OatAppLayout does this for you. With your own base page, put the theme behavior on the <html> tag:

// Java
TransparentWebMarkupContainer html = new TransparentWebMarkupContainer("html");
html.add(Oat.Behaviors.theme());
add(html);
<!-- HTML -->
<html wicket:id="html">
    <body>...</body>
</html>
