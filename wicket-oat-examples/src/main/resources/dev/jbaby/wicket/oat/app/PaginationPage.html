Oat Pagination Demo

Pagination reuses the button-group markup: a <menu class="buttons"> wrapping each page link in an <li>. Since only the data model knows which page is current, styling the active page (dropping .outline, adding aria-current="page") is the consumer's responsibility.

    •

    How to use

    // Java
add(Oat.Components.pagination("pagination", Model.ofList(pages), (item, page) -> {
    Link<Void> link = new Link<>("link") { public void onClick() {} };
    link.add(new Label("label", String.valueOf(page)));
    boolean current = page == currentPage;
    link.add(AttributeModifier.replace("class", current ? "button small" : "button outline small"));
    if (current) link.add(AttributeModifier.replace("aria-current", "page"));
    item.add(link);
}));
    <!-- HTML -->
<nav wicket:id="pagination">
    <menu wicket:id="menu">
        <li wicket:id="items">
            <a wicket:id="link" class="button outline small"><span wicket:id="label"></span></a>
        </li>
    </menu>
</nav>
