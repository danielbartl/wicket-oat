How to use

Encapsulated Fields (Recommended)

For most cases, use the specialized Oat... components. They handle labeling, feedback, and accessibility automatically.

// Java
form.add(new OatTextField<>("name", "Full Name", nameModel)
    .setPlaceholder(Model.of("John Doe"))
    .setRequired(true));

form.add(new OatDropdownChoice<String>("status", "Status", statusModel, statusChoices));
<!-- HTML -->
<div wicket:id="name"></div>
<div wicket:id="status"></div>

Custom Form Fields (Manual)

Use FieldBehavior on a container (like <label> or <div>) to style manual fields.

// Java
WebMarkupContainer container = new WebMarkupContainer("field");
container.add(new FieldBehavior());
container.add(new TextField<>("input", model));
<!-- HTML -->
<label wicket:id="field">
    Label Text
    <input wicket:id="input" type="text" />
</label>

Switches

Add SwitchBehavior to a CheckBox via the Oat factory.

// Java
checkBox.add(Oat.switchBehavior());
<!-- HTML -->
<input wicket:id="switch" type="checkbox" />

Feedback

Use OatSpinner, OatSkeleton components or their behaviors for loading states.

// Java - Components via Oat factory (recommended)
add(Oat.spinner("spinner", SpinnerBehavior.Size.SMALL));
add(Oat.skeleton("skeleton", SkeletonBehavior.Shape.LINE));

// Java - Behaviors via Oat factory
container.add(Oat.spinner(SpinnerBehavior.Size.SMALL));
container.add(Oat.skeleton(SkeletonBehavior.Shape.LINE));
<!-- HTML -->
<div wicket:id="spinner"></div>
<div wicket:id="skeleton"></div>

Progress & Meter

Use the specialized OatProgress and OatMeter components via the Oat factory. OatMeter supports advanced ranges like low, high, and optimum.

// Java - Simple Progress via Oat factory
add(Oat.progress("progress", 60));

// Java - Advanced Meter via Oat factory
add(Oat.meter("meter", 0.8)); // Default values 0-1 range
// or for full control:
add(new OatMeter("meter", 
    Model.of(0.8), // value
    Model.of(0),   // min
    Model.of(1),   // max
    Model.of(0.3), // low
    Model.of(0.7), // high
    Model.of(1)    // optimum
));
<!-- HTML -->
<progress wicket:id="progress"></progress>
<meter wicket:id="meter"></meter>
