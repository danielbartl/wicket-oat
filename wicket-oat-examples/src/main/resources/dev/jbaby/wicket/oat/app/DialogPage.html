Oat Dialog Demo

A modal dialog built on the native <dialog> element. Cancel, the Escape key and a click on the backdrop close it in the browser and tell the server, which runs onClose; Confirm validates the fields in its content and calls onConfirm over Ajax.

Confirmation

With a trigger label, the dialog renders its own button, which opens it without a server round trip.

// Java
add(new OatDialog("deleteDialog", Model.of("Delete item"), Model.of("Delete item?")) {
    @Override
    protected void onConfirm(AjaxRequestTarget target) {
        success("Item deleted.");
    }
}.setContent(new Label(OatDialog.CONTENT_ID, "This action cannot be undone."))
        .setConfirmLabel(Model.of("Delete"))
        .setConfirmVariant(OatVariant.DANGER));
<!-- HTML -->
<div wicket:id="deleteDialog"></div>

Drawers

OatDrawer is a dialog that slides in from the end of the screen - or its start or bottom, with setSide(...) - and is as tall as it, for what supports the page: filters, a record's details. It opens, confirms and closes as a dialog does, and the × in its corner closes it too.

Click Details in a row above for a drawer that only shows something.

 
// Java
OatDrawer filters = new OatDrawer("filtersDrawer", "Filters", "Filter orders") {
    @Override
    protected void onConfirm(AjaxRequestTarget target) {
        target.add(orders); // the fields have updated the filter's models
    }
};
filters.setContent(new OrderFilterPanel(OatDialog.CONTENT_ID, filter)).setConfirmLabel(Model.of("Apply"));

// Only showing something: no Cancel and Confirm, opened with a row's details
OatDrawer details = new OatDrawer("detailsDrawer", Model.of("Details"));
details.setFooterVisible(false);
