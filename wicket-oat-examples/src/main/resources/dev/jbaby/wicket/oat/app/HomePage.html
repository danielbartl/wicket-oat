Welcome to Wicket Oat

A modern, lightweight Wicket component library based on the Oat UI framework.

General Integration

Wicket Oat provides a simple facade to install all necessary resources and security settings in your WebApplication.init() method:

@Override
protected void init() {
    super.init();
    
    // Install Wicket Oat globally
    WicketOats.install(this);
}

What it does

Calling WicketOats.install(app) performs several actions:

  • Global Resources: Registers local oat.min.css and oat.min.js using getHeaderContributorListeners().
  • Security Policy: Configures the Content Security Policy (CSP) to allow local resources and necessary inline styles for components like Toast.

Security & CSP

To support Oat UI's dynamic features (like Toast notifications), the Content Security Policy should be configured to allow local resources and inline styles/scripts:

getCspSettings().blocking()
    .add(CSPDirective.STYLE_SRC, "'self'", "'unsafe-inline'")
    .add(CSPDirective.SCRIPT_SRC, "'self'", "'unsafe-inline'");

Theming System

Wicket Oat features a dynamic theming system based on the data-theme attribute. It supports both built-in and custom themes.

Programmatic Switching

Themes are managed via OatSession. You can switch themes from any Wicket component:

// Java
OatSession.get().setTheme(OatTheme.MIDNIGHT);

Custom Theme Definition

Themes are defined in CSS using variable overrides. Note that OatSession.setTheme(OatTheme) only accepts the built-in enum values above, so a custom theme name like this has to be applied by setting the data-theme attribute yourself (e.g. in markup or via an AttributeModifier) rather than through OatSession:

/* themes.css */
[data-theme="my-custom-theme"] {
    color-scheme: dark;
    --background: #123456;
    --primary: #ffcc00;
}

Advanced Usage: Programmatic Toasts

Use the ClientSideClickBehavior to trigger Oat UI's native JavaScript functions while remaining CSP compliant. ot.toast takes (message, title, options), so pass null for the title if you only want to set variant options:

// Java
button.add(new ClientSideClickBehavior("ot.toast('Operation successful!', null, {variant: 'success'})"));

Component Architecture

Wicket Oat follows two main patterns for implementing UI components:

  • Behaviors: Lightweight classes like ButtonBehavior, BadgeBehavior, or SpinnerBehavior that can be added to any Wicket component to apply Oat styling.
  • Components: Specialized classes like Alert, Badge, Progress, or Meter that encapsulate both behavior and markup logic.
